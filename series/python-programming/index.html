Python Programming

Never written a line of code? Start here. These notes take you from your very first print() to reading and writing the Python that machine-learning code is made of — no installs, everything runs live in the page.

Little theory, lots of doing: every concept is a 3–4 minute read followed by ~10 minutes of practice — worked examples, then graded problems you solve right here.

Where this leads.

This is Stage 1 of the pathway. By the end you'll be capable enough — with enough written work behind you — to start Machine Learning, the next stage. The final stretch is a bridge: the grammar of NumPy, pandas, matplotlib, seaborn, scikit-learn, PyTorch and Keras.

References & further reading

The book below is the reference material behind this series; everything else is supporting material the units draw on or point to.

  1. Thareja, R. — Python Programming: Using Problem Solving Approach, Oxford University Press. The reference material this series draws its pathway from — its ordering of topics, and its rhythm of brief theory followed by worked examples and plenty of graded practice, shape how these units are laid out. book
  2. The Python Tutorial — python.org's official tutorial. The canonical reference for every construct these units teach. docs.python.org
  3. Sweigart, A. — Automate the Boring Stuff with Python, 2nd ed. Free to read online; the same learn-by-doing spirit, aimed at practical office automation. book
